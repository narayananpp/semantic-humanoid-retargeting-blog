Single-Codex clothes-stand example: sources and attribution

Human demonstration: OMOMO, Jiaman Li, Jiajun Wu and C. Karen Liu,
Object Motion Guided Human Motion Synthesis (SIGGRAPH Asia 2023).
https://lijiaman.github.io/projects/omomo/

Initial humanoid reference: HOI-Retarget: Contact-Centric Retargeting for
Human-Object Interaction. https://github.com/leggedrobotics/hoi-retarget
The upstream motion dataset uses CC BY-NC-SA 4.0. Source-derived motion
measurements here are shared under those terms:
https://creativecommons.org/licenses/by-nc-sa/4.0/

Robot videos are rendered from recorded controller executions or verified
replays. The four intermediate replays and the final replay reproduce the
original recorded mean ADD. The initial evaluation uses verified identical input arrays. The mean ADD
history uses all recorded candidates. Plots are reconstructed from measurements;
they are not presented as plots the agent itself viewed. Inspected images are
resized versions of the original image-inspection inputs. Hand details are
labelled display crops, not separate image-inspection calls. Agent messages are
verbatim excerpts, with event lines and source hashes in trace.json.

No human body models, model weights, scene meshes or private run archives are
included in this directory. Object and robot asset attribution is retained in
../trace-explorer/vendor/DATA-NOTICE.txt and its accompanying license files.
