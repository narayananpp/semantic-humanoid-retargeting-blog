THE RECORDED EXPERIMENT

A recorded Astra refinement run.

This explorer uses the same recorded Astra session, selected trials and final execution as the architecture diagram. The initial motion is a separate evaluation of the identical input reference. Intermediate replays are verified against the original scores.

Messages are quoted from the recording with private paths and account identifiers removed. Tool labels summarize recorded operations. Images are those actually inspected by the agent. Playback uses saved poses and does not run new physics simulation.
