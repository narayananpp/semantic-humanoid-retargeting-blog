THE RECORDED EXPERIMENT

Four agents, one interaction.

The agents refine the clothes-stand interaction with frozen SONIC whole-body control and custom manipulation controllers. They can message one another, share controller files and test one another’s proposals. Agent 0 supplied the selected final execution.

Six 3D stages follow Agent 0: the initial reference, trials 001 and 004, an improved trial (055), a later regression (090), and the final execution. These are selected trials, not consecutive iterations. Intermediate replays are checked against the original object-tracking scores. The initial reference was evaluated separately with SONIC. The final motion is the original saved validation rollout.

Playback and activity follow Agent 0. The Exchanges tab retains the original messages across all four agents. Tool labels describe recorded operations. Agent messages are quoted, with private paths and account identifiers removed. Images are the views actually inspected by the agents. The explorer does not run new simulations.
